# 02. Что делать дальше по адаптации

## Purpose

Стажёр в любой момент узнаёт, на каком он этапе, что уже сделано и какие 1–3 шага следующие, и может отметить задачу выполненной, не открывая чек-лист.

## Триггеры (примеры фраз)

- «Что мне делать дальше?», «Я в первой неделе, что ещё не сделал?», «Какой у меня прогресс?»
- «Я прочитала документацию», «Я настроил окружение», «Отметь задачу выполненной»

## Нужные данные

| Данные | Откуда |
|---|---|
| Этап и проценты | `get_onboarding_progress` |
| Следующие шаги | `get_next_steps` |
| Задачи с id и статусами | `get_onboarding_plan` |

## Шаги диалога

1. «Что дальше?» → `get_onboarding_progress` + `get_next_steps` → этап, процент, 1–3 шага со ссылками.
2. «Я сделал X» → `get_onboarding_plan` → агент находит открытую задачу по названию → карточка `task_status`.
3. Подтверждение → `PATCH /onboarding/tasks/{id}` → «задача отмечена выполненной».
4. Если следующая задача — «Получить доступы», агент объясняет, что она закроется сама, и предлагает сценарий 04.

## Инструменты

Чтение: `get_onboarding_progress`, `get_next_steps`, `get_onboarding_plan`. Действие: `update_task_status` (только стажёр).

## Что требует подтверждения

Смена статуса задачи. Карточка: `type=task_status`, `params = {task_id, status, comment}`, `options.task_title`.

## Requirements

### Requirement: Навигация по плану

#### Scenario: AC-02-1 Следующие шаги
- GIVEN Анна на этапе «Первая неделя», две обязательные задачи этапа открыты
- WHEN она пишет «Что мне делать дальше?»
- THEN ответ называет этап, общий процент и открытые шаги со ссылками
- AND карточек нет

### Requirement: Отметка задачи

#### Scenario: AC-02-2 «Я сделал X»
- GIVEN у Анны открыта задача «Прочитать документацию команды»
- WHEN она пишет «Я прочитала документацию»
- THEN агент присылает карточку `task_status` с этой задачей и `status=done`
- AND после подтверждения задача в API в статусе `done`, прогресс вырос

#### Scenario: AC-02-3 Задача «Получить доступы»
- GIVEN задача `get_access` закрывается автоматически
- WHEN пользователь пишет «Я получил доступы к системам»
- THEN агент объясняет, что задача закроется сама, и предлагает запросить доступы
- AND карточка не создаётся

#### Scenario: AC-02-4 Задача не найдена
- GIVEN в плане нет задачи про «сертификацию»
- WHEN Анна пишет «Я прошла сертификацию»
- THEN агент показывает открытые задачи и спрашивает, какую отметить; карточки нет

#### Scenario: AC-02-5 Не стажёр
- GIVEN Елена — руководитель, инструмента `update_task_status` у неё нет
- WHEN она пишет «Я прочитала документацию»
- THEN агент объясняет, что отмечать задачи может только стажёр; карточки нет

## Ошибки и граничные случаи

| Ситуация | Поведение |
|---|---|
| Все обязательные задачи этапа закрыты | «Обязательные задачи этапа закрыты» |
| API вернул 409 на ручное закрытие `get_access` | объяснение из сообщения API |
| Сервис недоступен | «сервис временно недоступен», событие `error` с `retryable=true` |
