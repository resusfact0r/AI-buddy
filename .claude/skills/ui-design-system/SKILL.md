# Дизайн-система AI-buddy (стиль маркетплейса)

Визуальный язык: чисто, плотно, дружелюбно. Серый холст `canvas`, на нём белые карточки
`rounded-2xl` без рамок, одна главная голубая кнопка на экран, цветные «мягкие» плашки для
статусов, жирные заголовки, много воздуха внутри карточек и мало — между ними.

Работаем вместе со скилами **broom** и **unslop** (лежат рядом в `.claude/skills/`). Эта система — их
«baseline»: всё, что здесь задано, Broom считает решением продукта. Перед сдачей UI пройди
`broom check` и чек-лист Unslop `unslop/references/signs.md` — это ловит AI-слоп (градиенты,
свечения, эмодзи, капс с разрядкой, ✨ у AI, вес 800+, произвольные px).

Это стилистика «в духе», а не копия: **не** использовать логотип, фирменные названия,
иллюстрации и точные макеты Авито. Логотип продукта — `components/Logo.tsx`.

## Источник правды

- Токены: `web/tailwind.config.ts` (цвета, радиусы, тени, анимации). Не дублируй их хексами в коде.
- Глобальные классы: `web/src/index.css` — `.card`, `.input`, `.prose-chat`, фокус-кольцо.
- Примитивы: `web/src/components/ui/` — `Button`, `Badge`, `Field`, `Modal`, `Avatar`,
  `Skeleton`, `Spinner`, `States` (`EmptyState`, `ErrorState`).
- Склейка классов — `cn()` из `@/lib/cn`. Иконки — только `lucide-react`.

Сначала переиспользуй примитив. Новый примитив — только если паттерн встречается ≥2 раз; клади его
в `components/ui/` с теми же соглашениями (variants/sizes через `Record`, `forwardRef` для контролов).

## Токены

| Роль | Класс | Когда |
|---|---|---|
| Текст основной / вторичный / приглушённый | `text-ink` / `text-ink-soft` / `text-ink-muted` | заголовки и значения / описания / подписи, мета, плейсхолдеры |
| Фон страницы, вторичные поверхности | `bg-canvas` | body, вложенные блоки в карточке, secondary-кнопки, чипы |
| Разделители, рамки | `border-line`, `divide-line` | только когда без них не читается |
| Акцент | `brand` / `brand-soft` / `brand-strong` | главное действие, ссылки, активные элементы, фокус |
| Успех / ожидание / ошибка / AI | `ok` / `warn` / `danger` / `violet` + `-soft` | статусы, алерты; `violet` — всё, что делает AI |

Правила цвета:
- Плашка статуса = `bg-{tone}-soft text-{tone}`. Насыщенная заливка — только у кнопок.
- Активная вкладка навигации — `bg-ink text-white` (контрастный «чёрный» пилл), не голубой.
- Градиентов нет. Подложка hero-карточки — сплошной `bg-brand-soft`. Прогресс-бары — один сплошной цвет.
- Нет новых хексов в разметке. Если цвета не хватает — добавь токен в `tailwind.config.ts`.

Радиусы: контролы `rounded-xl` (14px), мелкие кнопки `rounded-lg`, карточки `rounded-2xl` (20px),
модалки и большие панели `rounded-3xl` (28px), бейджи и аватары `rounded-full`.
Тени: `shadow-card` у карточек, `shadow-pop` у всплывающего (модалки, поповеры, шиты). Других не вводить.

## Типографика (Manrope)

| Уровень | Классы |
|---|---|
| Заголовок страницы / hero | `text-title font-bold` (токен: 28/34, −0.02em) |
| Заголовок модалки | `text-xl font-bold` |
| Заголовок карточки/секции | `text-lg font-bold` |
| Основной текст | `text-body` (15/22, база контролов и чата) |
| Вторичный | `text-sm text-ink-soft` |
| Подпись, мета | `text-xs text-ink-muted` |
| Подпись над значением, шапка таблицы | `text-xs font-medium text-ink-muted` — обычный регистр, без `uppercase`/`tracking-wide` |

Вес: кнопки, бейджи, лейблы, навигация — `font-semibold`; заголовки — `bold` (никогда `extrabold`/`black`), большие числа — `font-bold tabular-nums tracking-tight`;
обычный текст — без веса. Курсив не используем. Числа в таблицах/счётчиках — `tabular-nums`.

## Отступы и сетка

- Контейнер задаёт `AppShell`: `max-w-[1400px] px-4 lg:px-6 py-6`. В страницах свои внешние поля не добавлять.
- Шаг 4px. Внутри карточки `p-4` (компактно) / `p-6` (основные), между карточками `gap-4`/`space-y-4`,
  внутри групп `gap-3`, иконка+текст `gap-1.5`–`gap-2`.
- Раскладка страниц: на `lg:` — две колонки на `minmax(0,…)` (как на главной:
  `grid-cols-[minmax(0,1fr)_minmax(0,1.1fr)]`) или основная + боковая `minmax(0,1fr)_360px`;
  на мобиле — одна колонка. Сетки карточек: `grid-cols-1 sm:grid-cols-2 xl:grid-cols-3`.
- Всегда `min-w-0` + `truncate` у текстов во flex-строках.

## Компоненты — как использовать

- **Button**: `primary` — одно главное действие на экран/карточку; `secondary` — соседние действия;
  `outline` — на белом рядом с primary или внутри алертов; `ghost` — иконочные/третичные;
  `danger` — разрушающее (мягкое, заливается на hover); `success` — «Одобрить». Размеры: `sm` в
  строках списков, `md` по умолчанию, `lg` в формах входа и модалках на мобиле. Асинхронно — `loading`,
  не руками дизейбл. Текст — глагол: «Отправить заявку», не «ОК».
- **Иконочная кнопка**: `grid h-9 w-9 place-items-center rounded-xl text-ink-soft hover:bg-canvas`
  + обязательно `aria-label`.
- **Badge**: статусы — через маппинг `Record<Status, {label, tone, icon}>` как в
  `features/requests/status.tsx`, иконка `h-3.5 w-3.5`. Соответствие: ожидание → `warn`,
  успех → `ok`, отказ/ошибка → `danger`, отмена/нейтрально → `neutral`, информация → `brand`, AI → `violet`.
- **Field + .input**: любой контрол формы оборачивай в `Field` (лейбл, hint, ошибка, aria).
  Ошибка — под полем, `text-danger`, по-человечески. Валидация — zod через `validate()` из `@/lib/zodForm`.
- **Карточка**: `section.card` с `aria-labelledby` на заголовок. Шапка: заголовок слева, действие
  (`Button size="sm" variant="ghost"`) справа. Вложенные блоки — `rounded-2xl bg-canvas px-3 py-2.5`.
- **Строка списка**: `flex items-center gap-3 px-4 py-3`, слева аватар/иконка в
  `grid h-10 w-10 place-items-center rounded-2xl bg-{tone}-soft text-{tone}`, по центру
  заголовок `font-semibold truncate` + мета `text-xs text-ink-muted`, справа бейдж/кнопка.
  Разделение строк — `divide-y divide-line`.
- **Modal**: только `components/ui/Modal` (Radix). Боковые панели — как `ArticleSheet`.
  Кнопки внизу: справа primary, слева/рядом secondary «Отмена»; на мобиле — во всю ширину.
- **Тосты**: только `@/lib/toast` — `toast.success(...)` коротко и по факту («Заявка отправлена»),
  ошибки API — `notifyError(error, retry)`.

## Состояния — обязательны для каждого блока с данными

1. Загрузка → `Skeleton` той же формы, что контент (для простой карточки — `SkeletonCard`) (с `role="status"` и `aria-label`). Спиннер — только в кнопках и мелких инлайн-местах.
2. Ошибка → `ErrorState` (`compact` внутри карточки) с `onRetry`.
3. Пусто → `EmptyState` с понятным заголовком, подсказкой и, если можно, действием.
4. Оптимистичные изменения — сразу показывать результат, откатывать с тостом при ошибке.

## Движение

Только `animate-fade-up` для появления, `transition-colors` для hover. Анимируются только `transform` и `opacity`
(прогресс — `origin-left` + `scaleX`, 200ms ease-out), не `width`. `animate-pulse` — только у скелетонов и живого
курсора стрима. Без bounce/scale/параллакса.
`prefers-reduced-motion` уже глушится глобально — не обходить.

## Тексты (UI-копирайт)

На «ты» не переходим, обращаемся на «вы» нейтрально или безлично. Коротко, конкретно, по-русски,
без канцелярита и капслока. Кнопки — глаголы, статусы — причастия («Одобрено»), ошибки — что
случилось и что делать («Не удалось загрузить заявки. Повторите попытку»). Ёлочки «», тире —.
Эмодзи в интерфейсе нет совсем, восклицательных знаков тоже. Похвала вида «Отличная работа!» → факт («План пройден полностью»).

## Доступность

Фокус-кольцо глобальное — не отключать `outline` без замены. Все иконки декоративные `aria-hidden`,
у иконочных кнопок `aria-label`. Цвет — не единственный носитель смысла (у статусов иконка + текст).
Контраст текста не ниже `ink-soft` на белом; `ink-muted` — только для вторичных подписей.
Кликабельная зона ≥ 36px (`h-9`). Семантика: `section/nav/main`, заголовки по порядку.
