## Открытые вопросы

**Бэкенд 1**

1. **В заявках нет имени автора** — только `user_id`. Руководитель видит «anna» и в чате, и на странице согласований. Нужно поле `user: {id, full_name}` в `GET /requests`, `/requests/{id}`, `/approvals/pending`.
2. **Статьи команды одинаковые.** У «Код-ревью», «Стендап» и остальных статей команды один и тот же текст. На «Что такое Grafana?» агент отвечает статьёй про код-ревью. Для сценария 3 нужны разные тексты статей.
3. **Нет `GET /people`.** Инструмент `find_person` получает 404, поэтому наставник не может попросить «покажи план Бориса» по имени.
4. **Нет `GET /metrics/summary`** — он был в постановке и нужен для слайда про метрики.
5. **Одно сообщение на все ошибки валидации отгула** («Укажите будущие даты, период до 14 дней и корректный reason_type»). Агент не может объяснить, что именно не так.
6. **В `GET /teams/{id}` нет каналов и правил** — на «Какие у нас каналы?» ответ без каналов.
7. **Сиды расходятся со сценарием демо.** У Анны «Прочитать документацию» уже выполнена, поэтому фраза «Я прочитала документацию» из сценария не даёт карточку. Рабочая замена: «Я настроил окружение». Полные имена — только «Анна», «Елена».
8. **Покрытие 80,7%** при пороге «больше 80%» — запас в одну-две функции.
9. `make seed` очищает общий Redis, включая карточки и историю агента. Для сброса перед демо это уместно, но активные карточки пропадут.

**Фронтенд**

10. На странице согласований и в «Моих заявках» показывается полный 64-символьный идентификатор заявки и код системы (`kafka`) вместо названия. Имя автора появится после пункта 1.
11. `live.test.ts` проходит только на свежих данных: после одного прогона (или ручной работы под Борисом) падает на шаге «Какие доступы мне нужны?».
12. `web/Dockerfile` начинается с `# syntax=docker/dockerfile:1` — сборка каждый раз обращается к Docker Hub и падает, если он недоступен. Строку можно убрать.

**Общее**

13. Репозиторий приватный: статус GitHub Actions снаружи не виден, доступ аккаунту `hack-and-change-2026` нужно выдать.
14. «В пятницу», сказанное в пятницу, даёт следующую пятницу — это задумано, но на демо в пятницу стоит помнить.
15. С реальной LLM продукт не проверялся.

## Новые открытые вопросы

**Бэкенд 1**

16. **Без Redis API отвечает медленно.** `GET /onboarding/plan`, `/progress`, `/access/overview` ждут Redis по 5 с; вход (`POST /auth/login`) и `/readyz` отвечают `503`. Кэш стоит читать с коротким таймаутом, а вход — не блокировать полностью.

**Фронтенд**

18. Заявки на отгул показываются без года («ср, 10 марта» для марта 2027).

**Агент (известные ограничения)**

19. С реальной моделью, которая не открывает статью, в `sources` попадают первые три результата поиска, включая нерелевантные.
20. При отказе Redis на старте агент до перезапуска работает на хранилище в памяти процесса.
